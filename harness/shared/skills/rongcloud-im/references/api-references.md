# 融云 IM API 参考

本文列出 IMLib 和 IMKit 组件的官方 API 参考链接。仅当用户询问需要查阅官方文档的具体 API 方法、类型、事件或组件属性时加载。

## IMLib

| SDK / 组件 | API 参考 |
| --- | --- |
| Web IMLib | https://doc.rongcloud.cn/apidoc/im-web/latest/zh_CN/|
| Android IMLib | https://doc.rongcloud.cn/apidoc/imlib-android/latest/zh_CN/html/|
| iOS IMLib | https://doc.rongcloud.cn/apidoc/imlib-ios/latest/zh_CN/documentation/rongimlib/?language=objc|
| Flutter IMLib | https://pub.dev/documentation/rongcloud_im_wrapper_plugin/latest/index.html|

IMKit 的组件和扩展 API 应从 `references/llms.txt` 定位目标平台当前文档；若项目已安装 IMKit，同时以安装版本的公开接口为准。
